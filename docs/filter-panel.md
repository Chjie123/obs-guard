# 滤镜控制面板

本文对应 obs-guard 0.1.3，说明「违禁内容遮挡」滤镜面板中每个参数的含义、取值范围与调参依据。

面板按六组排列，共 31 个可设参数（检测区域含百分比与像素两套，各 4 项；同一时刻只显示其中一套），另有 2 个按钮与 3 段说明文字。分组顺序与调试顺序一致：先确认挂载与区域，再配模型，最后调样式与平滑。

带量纲的参数在输入框内直接显示单位（`fps`、`%`、`px`、`ms`、`个`）。置信度阈值、NMS IoU、不透明度、外扩比例与目标类别是无量纲比值或文本，不显示单位。

---

## 1. 基本

| 参数 | 控件 | 取值 | 默认 | 说明 |
|---|---|---|---|---|
| 启用检测 | 复选 | 开 / 关 | 开 | 总开关。关闭后画面直通，不再取帧与推理，已产生的遮罩立即清空 |
| 检测频率 | 滑块 | 0 – 显示器刷新率（fps） | 10 | 每秒推理次数。**遮罩始终逐帧绘制**，降低该值只减少 CPU/GPU 占用；0 表示停止推理，只保留已有遮罩的淡出 |
| 推理不可用时 | 下拉 | 直通画面 / 全屏遮挡 | 直通画面 | `直通`：模型缺失或推理异常时停止遮挡并写告警，保直播；`全屏遮挡`：持续全屏遮罩直到恢复，保合规 |

`检测频率` 的上限取自本机显示器支持的最高刷新率（枚举全部显示模式取最大值，探测失败时按 60）。超过屏幕刷新率没有意义：渲染一帧只会产生一次遮罩更新。

`检测频率` 与 `⑤ 平滑` 的 `目标消失后保持` 需要配套：保持时长应大于检测间隔。10 fps 对应间隔 100 ms，保持 300 ms 可覆盖约 3 次漏检。

---

## 2. 检测区域

| 参数 | 控件 | 取值 | 默认 | 说明 |
|---|---|---|---|---|
| 坐标系 | 下拉 | 百分比 / 像素 | 百分比 | 百分比与分辨率无关；像素按当前源分辨率换算 |
| X | 滑块 / 输入 | 百分比 0 – 100 %，像素 0 – 8192 px | 0 | 相对画面左上角的横向起点 |
| Y | 滑块 / 输入 | 同上 | 0 | 纵向起点 |
| 宽 | 滑块 / 输入 | 百分比 1 – 100 %，像素 1 – 8192 px | 100 / 1280 | 区域宽度。下限为 1，防止拖出零面积 |
| 高 | 滑块 / 输入 | 同上 | 100 / 720 | 区域高度 |

两套坐标系各有独立的一组 X / Y / 宽 / 高，面板只显示当前选中的那一组。

只有该区域内的目标会被检测与遮挡，区域外的像素不参与推理。

使用像素坐标时，若滤镜挂在「显示器采集」源上，像素坐标即屏幕坐标；挂在摄像头源上则是摄像头画面坐标，不是屏幕坐标。

---

## 3. 模型

| 参数 | 控件 | 取值 | 默认 | 说明 |
|---|---|---|---|---|
| YOLO 模型（.onnx） | 文件选择 | `.onnx` 路径 | 空 | 输入尺寸与类别名均从模型读取，无需手填 |
| 推理设备 | 下拉 | 自动 / DirectML / CPU | 自动 | 自动优先 DirectML，不可用时回退 CPU。CPU 延迟显著高于 GPU |
| 置信度阈值 | 滑块 | 0.01 – 0.99 | 0.35 | 低于该分数的目标不生成遮罩。调高减少误遮，调低提高召回 |
| NMS IoU 阈值 | 滑块 | 0.10 – 0.95 | 0.45 | 重叠框抑制强度。同一目标被重复检出时调低 |
| 单帧最多目标数 | 滑块 | 1 – 64 个 | 32 | 按置信度排序后截断 |
| 遮罩矩形上限 | 滑块 | 1 – 32 个 | 16 | 同时绘制多少个遮罩矩形，超出按置信度截断 |
| 目标类别 | 文本 | 类别名或索引，逗号分隔 | 空 | 留空表示全部类别，例如 `person, head` |

`单帧最多目标数` 限制推理结果的保留数量，`遮罩矩形上限` 限制实际绘制的矩形数量，两者独立：前者影响跟踪与统计，后者直接决定着色器的绘制开销。绘制上限对应的着色器槽位固定为 32，因此可设范围为 1 – 32；提高该值会增加逐像素的矩形判定次数，通常 16 足够。

`目标类别` 填了模型中不存在的名字不会报错，但会导致零命中——这是「模型加载成功却没反应」的常见原因，排查时先清空该字段。

## 4. 遮罩样式

| 参数 | 控件 | 取值 | 默认 | 说明 |
|---|---|---|---|---|
| 遮罩方式 | 下拉 | 纯色 / 模糊 / 马赛克 | 马赛克 | 纯色无法被生成模型还原；模糊仅建议用于中低风险 |
| 颜色 | 取色 | 任意 | 黑 | 仅纯色模式生效。存储格式为 `0xAABBGGRR` |
| 不透明度 | 滑块 | 0.05 – 1.00 | 0.85 | 1.0 完全不透。低于约 0.3 时内容仍可辨认 |
| 模糊半径 | 滑块 | 2 – 64 px | 16 px | **仅模糊模式显示**。以 1080p 为基准，随分辨率等比缩放 |
| 马赛克块大小 | 滑块 | 4 – 64 px | 16 px | **仅马赛克模式显示**。数值越大越糊，16 以下仍可能还原出轮廓 |
| 框体外扩比例 | 滑块 | 0 – 0.30 | 0.10 | 每边按框宽/框高的该比例外扩，防边缘泄漏。0.10 即各边扩大 10% |
| 额外边距 | 滑块 | 0 – 24 px | 4 px | 在外扩之后追加固定像素，处理细碎边缘 |

外扩量为 `框体外扩比例 × 框宽`（左右）与 `× 框高`（上下），四边各自独立，之后再叠加 `额外边距`。小目标主要靠边距，大目标主要靠比例。

模糊半径与块大小都以帧高的 1/1080 为缩放基准，因此 1080p、1440p、4K 下观感一致，不需要换分辨率后重调。

## 5. 平滑

| 参数 | 控件 | 取值 | 默认 | 说明 |
|---|---|---|---|---|
| 目标消失后保持 | 滑块 | 0 – 1000 ms | 300 ms | 单帧漏检不立即撤遮，抑制闪烁 |
| 淡出时长 | 滑块 | 0 – 800 ms | 180 ms | 保持结束后的渐隐过渡时间 |

两段计时独立：`保持` 期间遮罩全强度，`淡出` 期间线性降到 0。闪烁明显时优先加大保持时长，撤遮太生硬时加大淡出时长。

目标首次出现的前 3 帧属于「疑似」状态，不透明度按 55% 绘制，累计 3 帧命中后转为「已确认」，恢复到设定值。该比例为内部常量，不开放配置。

## 6. 诊断

| 参数 | 控件 | 取值 | 默认 | 说明 |
|---|---|---|---|---|
| 显示检测区域边框 | 复选 | 开 / 关 | 关 | 用品红框标出实际送检区域，验证坐标是否正确 |
| 显示命中框 | 复选 | 开 / 关 | 关 | 用绿框标出每个命中目标，与遮罩样式无关 |
| 显示置信度 | 复选 | 开 / 关 | 关 | 在命中框左上角叠加两位数读数，数值为置信度 ×100 |
| 推理状态 | 只读 | — | — | 显示 `后端 · 输入尺寸 · 类别数`，例如 `DirectML · 640x384 · 2 类` |
| 刷新状态 | 按钮 | — | — | 重新拉取推理状态。模型加载成功或失败的信息只在此更新 |
| 测试遮罩 | 按钮 | — | — | 在当前检测区域叠加 3 秒样本遮罩，不依赖模型 |

三个「显示」开关的画面元素都会进入输出，即出现在直播与录制内容中。排障结束应关闭。

「测试遮罩」不经过推理链路，用于把问题区间一分为二：测试遮罩可见说明挂载、坐标系与着色器正常，问题在模型或检测；测试遮罩也不可见说明问题在滤镜挂载或渲染。

---

## 7. 排查顺序

画面没有反应时，按以下顺序判断，可一次定位断点：

| 步骤 | 观察 | 结论 |
|---|---|---|
| 1 | 勾选「显示检测区域边框」后没有品红框 | 滤镜未挂载、挂到了错误的源，或着色器未加载。查看 OBS 日志中 `obs-guard` 的报错 |
| 2 | 有品红框，但「测试遮罩」不出效果 | 渲染链路或着色器异常，与模型无关 |
| 3 | 推理状态不是 `后端 · HxW · N 类` | 模型未加载，检查路径、运行库与推理设备 |
| 4 | 打开「显示命中框」，无绿框 | 检测未命中：降低置信度阈值、清空目标类别、确认检测区域 |
| 5 | 有绿框但位置偏移 | 坐标系或 X/Y/宽/高 填错；像素坐标用在了非屏幕源上 |
| 6 | 有绿框、位置正确，画面却没变化 | 遮罩样式问题：检查遮罩方式与不透明度 |

---

## 8. 典型配置

| 场景 | 关键参数 |
|---|---|
| 全屏监控 | 坐标 0/0/100/100，检测频率 8，目标类别留空 |
| 只查右下角二维码位 | 坐标 55/55/40/40，检测频率 10，阈值 0.3 |
| 高危内容合规 | 遮罩方式纯色，不透明度 1.0，推理不可用时全屏遮挡 |
| 低配机器 | 检测频率 5，缩小检测区域，遮罩方式马赛克 |

## 附录：配置键对照

面板标签与 `obs_data` 键一一对应，脚本或配置文件操作时使用右列。

| 面板标签 | 配置键 | 类型 |
|---|---|---|
| 启用检测 | `enabled` | bool |
| 检测频率 | `det_fps` | int |
| 推理不可用时 | `fail_mode` | int（0 直通 / 1 全屏） |
| 坐标系 | `coord_mode` | int（0 百分比 / 1 像素） |
| X / Y / 宽 / 高（百分比） | `pct_x` / `pct_y` / `pct_w` / `pct_h` | double |
| X / Y / 宽 / 高（像素） | `px_x` / `px_y` / `px_w` / `px_h` | int |
| YOLO 模型 | `model_path` | string |
| 推理设备 | `device` | int（0 自动 / 1 DirectML / 2 CPU） |
| 置信度阈值 | `conf` | double |
| NMS IoU 阈值 | `iou` | double |
| 单帧最多目标数 | `max_det` | int |
| 遮罩矩形上限 | `mask_limit` | int |
| 目标类别 | `class_filter` | string |
| 遮罩方式 | `mask_kind` | int（0 纯色 / 1 模糊 / 2 马赛克） |
| 颜色 | `mask_color` | int（`0xAABBGGRR`） |
| 不透明度 | `mask_opacity` | double |
| 模糊半径 | `blur_px` | double |
| 马赛克块大小 | `block_px` | double |
| 框体外扩比例 | `expand` | double |
| 额外边距 | `pad_px` | double |
| 目标消失后保持 | `hold_ms` | int |
| 淡出时长 | `fade_ms` | int |
| 显示检测区域边框 | `debug_roi` | bool |
| 显示命中框 | `debug_box` | bool |
| 显示置信度 | `debug_conf` | bool |
